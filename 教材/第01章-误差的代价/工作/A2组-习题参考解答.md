## 题1：浮点表示、误差尺度与求和顺序

### （1）表示与舍入：8分

由 $0.15625=5/32=1/8+1/32$，有

$$0.15625=0.00101_2=1.01_2\times2^{-3}.$$

只需3个有效二进制位，指数也在范围内，故两种dtype都能精确表示。对于0.1，反复乘2取整数部分得到

$$0.1_{10}=0.0001100110011\cdots_2=1.100110011\cdots_2\times2^{-4}.$$

最简分数 $1/10$ 的分母含因子5，不是2的幂，因此不能成为有限二进制小数；两种dtype都只能近似。

4位格式的相邻候选数为

$$a=1.100_2\times2^{-4}=\frac{12}{128}=0.09375,\quad
b=1.101_2\times2^{-4}=\frac{13}{128}=0.1015625.$$

与 $1/10$ 的距离分别为 $1/160$ 和 $1/640$，所以最近舍入取 $b$。绝对误差为 $1/640=0.0015625$，相对误差为 $(1/640)/(1/10)=1/64=0.015625$。

评分建议：两种二进制与可表示性各2分；两个候选及最近判断2分；两种误差2分。

### （2）精度与小数求和：6分

含首位共 $p$ 位时，1处向上间隔 $\varepsilon=2^{1-p}$；最近舍入的单位舍入误差 $u=2^{-p}$。

| dtype | $p$ | $\varepsilon$ | $u$ |
| --- | --- | --- | --- |
| float32 | 24 | $2^{-23}\approx1.1920929\times10^{-7}$ | $2^{-24}\approx5.9604645\times10^{-8}$ |
| float64 | 53 | $2^{-52}\approx2.2204460\times10^{-16}$ | $2^{-53}\approx1.1102230\times10^{-16}$ |

对精确参考 $3/10$，实际结果为：

| dtype | 存储结果转Python float显示 | 绝对误差 | 相对误差 |
| --- | --- | --- | --- |
| float32 | 0.30000001192092896 | $1.1920928955\times10^{-8}$ | $3.9736429850\times10^{-8}$ |
| float64 | 0.30000000000000004 | $4.4408920985\times10^{-17}$ | $1.4802973662\times10^{-16}$ |

注意，Python字面量0.3也已被舍入，用浮点 `result-0.3` 不能作为对精确 $3/10$ 的误差。本题用 `Fraction.from_float` 恢复存储数对应的精确分数，再与 `Fraction(3,10)` 相减。将float32转成Python float显示不会增加其原有准确度，只是精确容纳这个已舍入的float32数。

评分建议：间隔与 $u$ 关系2分；正确独立参考2分；两种误差与dtype2分。

### （3）顺序求和：7分

精确实数目标均为1。

| dtype | 顺序 | 实测和 | 绝对误差 | 相对误差 |
| --- | --- | --- | --- | --- |
| float32 | $[10^{16},1,-10^{16}]$ | 0 | 1 | 1 |
| float32 | $[10^{16},-10^{16},1]$ | 1 | 0 | 0 |
| float64 | $[10^{16},1,-10^{16}]$ | 0 | 1 | 1 |
| float64 | $[10^{16},-10^{16},1]$ | 1 | 0 | 0 |

float64在 $10^{16}$ 处的向上间隔为2，加1落在中点，通常的最近偶数舍入使结果仍为 $10^{16}$；再减去原数得到0。float32间隔更大，1也会丢失。float32不能精确表示 $10^{16}$，但同dtype下正负两个大数对应相反的机器数，第二种次序先相消，再加1得到1。必须区分实数目标与已舍入输入，不能说float32原本精确存储了 $10^{16}$。

评分建议：明确逐次同dtype运算2分；结果与误差3分；舍入和顺序原因2分。

### （4）辨析：4分

两句均错误。格式化显示只改变字符，不增加存储有效位数。真值为0时相对误差公式分母为0，因此不定义，即使绝对误差也是0仍不能作 $0/0$。应报告绝对误差或明示外部非零尺度。每句判断与解释各2分。

### 题1参考实现

下面的代码接在本文件末尾“公共导入与函数”之后运行；完整独立脚本另附。

## 题2：有理化、Taylor截断与步长选择

### （1）等价改写：7分

因 $x\ge0$，$\sqrt{x+1}+\sqrt x>0$，乘以共轭式得到

$$g(x)=\frac{(x+1)-x}{\sqrt{x+1}+\sqrt x}
=\frac1{\sqrt{x+1}+\sqrt x}.$$

本次float64直接式为0，有理化式为 $5\times10^{-9}$，80位参考约为

$$g(10^{16})=4.99999999999999987500000000000000625\cdots\times10^{-9}.$$

直接式相对误差为1；有理化式相对误差约 $4.5922560830\times10^{-17}$。误差首先在 $x+1$ 处出现：结果舍入回 $x$。不能只归因于最后的减法，两个根此时已经相同。有理化保留精确分子1，分母的舍入对本例影响较小。

评分建议：适用域与推导2分；参考与两种相对误差3分；舍入起点2分。

### （2）误差推导：7分

对某个 $\xi\in(1,1+h)$，

$$e^{1+h}=e+he+\frac{h^2}2e^\xi,$$

故

$$D_h-e=\frac h2e^\xi>0,\qquad |D_h-e|\le\frac h2e^{1+h}.$$

对 $0<h\le0.1$，还可统一写成 $|D_h-e|\le he^{1.1}/2$。精确算术下是一阶截断误差，不应把这一界直接当成浮点实现的总误差界。

令 $F(h)=Ah+Bu/h$，则 $F'(h)=A-Bu/h^2$。在 $h>0$ 时唯一驻点为

$$h_{\rm bal}=\sqrt{Bu/A},\qquad F''(h)=2Bu/h^3>0.$$

该点最小化的是估计式，最小值为 $2\sqrt{ABu}$。真实舍入误差不严格服从连续曲线 $Bu/h$，$A,B$也未被精确确定，函数计算及 $1+h$ 的表示影响实际结果，因此它不是本题最优机器步长的严格公式。

评分建议：Taylor与余项3分；误差界1分；平衡步长2分；局限1分。

### 题2参考实现

```python
print('题2：有理化和差分步长')
x = 1e16
naive = math.sqrt(x + 1) - math.sqrt(x)
stable = 1 / (math.sqrt(x + 1) + math.sqrt(x))
with localcontext() as c:
    c.prec = 80
    xd = Decimal('1e16')
    reference = (xd + 1).sqrt() - xd.sqrt()
    stable_error = abs(decimal_float(stable) - reference) / abs(reference)
    derivative = Decimal(1).exp()
    scans = []
    for k in range(1, 17):
        h = 10.0 ** (-k)
        approx = (math.exp(1 + h) - math.exp(1)) / h
        err = abs(decimal_float(approx) - derivative)
        scans.append((h, approx, float(err)))
assert naive == 0 and stable_error < Decimal('1e-14')
assert scans[-1][1] == 0 and (1 + 1e-16) - 1 == 0
print('direct=', naive, 'rationalized=', stable, 'reference=', reference)
print('rationalized relative error=', stable_error)
for row in scans:
    print('h=%9.1e  D_h=%.16g  abs_error=%.8e' % row)
best = min(scans, key=lambda r: r[2])
print('best scanned point:', best)
results['Q2'] = {'rationalized_relative_error': str(stable_error), 'best_scanned_point': best}
```

## 题3：输入敏感性与算法稳定性

### （1）一般公式：7分

若 $f$ 在 $x$ 可微，则

$$f(x+d)-f(x)=f'(x)d+o(|d|).$$

当 $x\ne0,f(x)\ne0$ 时，用输出与输入各自的相对变化作比：

$$\lim_{d\to0,d\ne0}\frac{|f(x+d)-f(x)|/|f(x)|}{|d|/|x|}
=\left|\frac{xf'(x)}{f(x)}\right|.$$

这是局部极限，不能声称任意有限扰动都服从严格等式。对 $q(x)=1/(1-x)$，定义域排除1，$q'=1/(1-x)^2$，所以 $\kappa_q=|x/(1-x)|$。题设点为9999。

评分建议：一阶展开2分；非零条件与极限2分；$q$求导、条件数及数值3分。

### （2）有限扰动：8分

在 $x\ne1$、$x+d\ne1$ 时，

$$\frac{q(x+d)-q(x)}{q(x)}=\frac d{1-x-d},$$

因此对 $x\ne0,d\ne0$，放大率为

$$R(d)=\frac{|d/(1-x-d)|}{|d/x|}=\left|\frac{x}{1-x-d}\right|.$$

| $d$ | 输入相对变化 | 输出相对变化 | 放大率 |
| --- | --- | --- | --- |
| 1e-06 | 1.0001000100e-06 | 1.0101010101e-02 | 10100.0000000000 |
| 1e-08 | 1.0001000100e-08 | 1.0001000100e-04 | 10000.0000000000 |
| 1e-10 | 1.0001000100e-10 | 1.0000010000e-06 | 9999.0099990100 |

随着 $d$ 变小，结果趋近9999；第一行约10100并非算法失稳，而是有限扰动与局部极限的差别。若 $d=10^{-4}$，则 $x+d=1$，$q$无定义，不能给出有限放大率，不能照搬局部条件数。跨越极点的变化也不属于相同局部线性解释。

评分建议：相对变化与比值闭式3分；三行正确数据3分；趋近解释及极点2分。

### （3）同问题的不同算法：6分

当 $x>0$，

$$g'(x)=\frac1{2\sqrt{x+1}}-\frac1{2\sqrt x}
=-\frac{g(x)}{2\sqrt x\sqrt{x+1}},$$

故

$$\kappa_g(x)=\left|\frac{xg'(x)}{g(x)}\right|
=\frac12\sqrt{\frac{x}{x+1}}<\frac12,\qquad
\lim_{x\to\infty}\kappa_g(x)=\frac12.$$

对单输入 $x$ 的相对扰动，这个问题在大 $x$ 处并不病态。题2失败表明该直接实现数值不可靠，不能据此断定问题病态。若改成独立输入 $a,b$ 的减法 $a-b$，输入的允许扰动集合发生变化，其相对敏感性可由 $(|a|+|b|)/|a-b|$ 刻画；当两数很近时可能很大。这是不同的数学输入模型。

评分建议：求导与条件数3分；极限1分；算法/问题区别及输入模型2分。

### （4）误差尺度：4分

$x=0$ 时 $|d|/|x|$ 不定义；$f(x)=0$ 时相对输出变化不定义。若可微，可以用绝对条件数 $|f'(x)|$ 研究小的绝对输入变化，或先声明非零的外部输入/输出尺度。对 $g$ 在0处还应注意右导数不有限，不能只把绝对条件数当作必然存在的补救。零真值处不能凭空把相对误差设为0。

评分建议：两个分母限制2分；替代尺度及其假设2分。

### 题3参考实现

## 题4：稳定softmax、损失与梯度尺度

### （1）推导：7分

令 $m=\max_jz_j$。在实数算术中，同除 $e^m$ 得

$$p_i=\frac{e^{z_i-m}}{\sum_j e^{z_j-m}},\qquad
\ell=-\log p_y=(m-z_y)+\log\sum_j e^{z_j-m}.$$

全部logits有限、移位差可处理时，指数输入不大于0且至少一项为1，缓解正指数上溢和全体指数下溢。但小概率仍可下溢为0；NaN、无穷输入或极端反号有限数的移位减法溢出需另行处理。

求梯度时可直接从光滑的等价式 $\ell=\log\sum_j e^{z_j}-z_y$ 求导：

$$\frac{\partial\ell}{\partial z_i}=\frac{e^{z_i}}{\sum_j e^{z_j}}-\mathbf1_{i=y}=p_i-\mathbf1_{i=y}.$$

这避免了在最大值并列时对单独的 $\max$ 函数求导的表面困难；最终损失本身仍光滑。

评分建议：两种稳定式3分；假设与剩余风险2分；梯度2分。

### （2）两种精度对照：7分

### （3）损失和更新：7分

第三组中，稳定softmax的 $p_2$ 在float64下为0，所以 $-\log p_2=+\infty$。对数域公式给出

$$\ell=(1000-(-1000))+\log(1+e^{-1000}+e^{-2000})\approx2000.$$

精确实数损失略大于2000，但这项极小修正在本次浮点数及80位Decimal中均不可分辨，因此数值结果2000合理，不应说数学真值严格等于2000。

参数更新得到：float32保存为1，float64保存为0.99999999。float32中更新量小于1附近可分辨尺度，结果舍入回1。无NaN并不排除下溢、微小更新丢失或其他误差；损失、概率局部计算成功也不证明模型、优化器或训练全过程正确。

评分建议：两种损失及失败解释3分；两种参数更新2分；“无NaN”局限2分。

### （4）局部梯度核验：4分

```python
import math, json
from pathlib import Path
from decimal import Decimal, localcontext
from fractions import Fraction
import numpy as np

def decimal_float(v):
    return Decimal.from_float(float(v))

def softmax_reference(values):
    with localcontext() as c:
        c.prec = 80
        a = [Decimal(str(v)).exp() for v in values]
        total = sum(a)
        return [v / total for v in a]

def stable_softmax(z):
    a = np.exp(z - np.max(z))
    return a / np.sum(a, dtype=z.dtype)

def loss_value(z, y):
    m = np.max(z)
    return (m - z[y]) + np.log(np.sum(np.exp(z - m), dtype=z.dtype))
```
