# 非线性方程与方程组的数值解法

> **本章导读：从区间搜索到迭代逼近**
>
> **非线性现象**广泛存在于自然科学与工程问题中。线性模型通常只是真实系统在小范围下的近似；想要获得更高精度的结果，必须直接处理非线性模型，是非线性科学的核心任务。
>
> 本章研究单变量非线性方程 $f(x)=0$ 的求根，从最简单的二分区间搜索，过渡到一般迭代法、牛顿迭代等加速收敛算法。我们的目标：在计算机上用数值方法找到方程的根，理解不同方法的收敛性、收敛速度与适用范围。

非线性问题在科学与工程计算中占有重要地位。很多熟知的线性模型都是非线性问题在一定假设下的简化近似。为得到更贴合实际的结果，需要直接求解非线性模型。非线性模型可分为无限维（如非线性微分方程）与有限维；在计算机数值计算中，最终一般都转化为单变量非线性方程或非线性方程组求解。

从线性到非线性是本质的跨越：非线性方程不一定存在显式求根公式，根的个数、分布更加复杂，求解思路也与线性方程完全不同。本章先讨论单变量非线性方程求根，最后简要介绍非线性方程组数值解法。

## 方程求根与二分法

### 基本概念与有根区间

本章主要求解单变量非线性方程

$$
f(x) = 0,
$$

（式 1）

式中 $x\in\mathbb{R}$，函数 $f(x)\in C[a,b]$，区间 $[a,b]$ 也可以是无穷区间。

若实数 $x^*$ 满足 $f(x^*)=0$，则称 $x^*$ 是方程（式 1）的根，也称 $x^*$ 为函数 $f(x)$ 的零点。

若 $f(x)$ 可以分解为

$$
f(x) = (x - x^*)^m g(x),
$$

其中 $m$ 为正整数，且 $g(x^*)\neq0$，则称 $x^*$ 是方程的 **$m$ 重根**，或称 $f(x)$ 的 $m$ 重零点。$m=1$ 时称为单根。

若 $x^*$ 是 $f(x)$ 的 $m$ 重零点，且 $g$ 充分光滑，则

$$
f(x^*) = f'(x^*) = \cdots = f^{(m-1)}(x^*) = 0,\quad f^{(m)}(x^*)\neq0.
$$

- **代数方程**：$f(x)$ 为多项式

  $$
  f(x) = a_0 x^n + a_1 x^{n-1} + \cdots + a_{n-1} x + a_n,\quad a_0\neq 0.
  $$

  由代数基本定理：$n$ 次代数方程在复数域内恰有 $n$ 个根（计重数）。$n=1,2$ 有初等求根公式；$n=3,4$ 的求根公式形式复杂，不适合数值计算；当 $n\ge5$ 时，不存在仅由四则运算与根式表达的通用求根公式，只能依靠数值方法。

- **超越方程**：含指数、对数、三角函数等超越函数，例如

  $$
  e^{-x/10}\sin 10x = 0,
  $$

  这类方程可能有无穷多个实根，根的分布依赖于求解区间。

非线性方程一般没有显式求根公式，因此主要依靠**迭代法**求解。迭代法需要先确定根所在区间：

**介值定理**：若 $f\in C[a,b]$，且 $f(a)f(b)<0$，则至少存在一点 $x^*\in(a,b)$ 使得 $f(x^*)=0$。此时称 $[a,b]$ 为**有根区间**。

介值定理仅保证根的存在性，不保证唯一性。若函数 $f(x)$ 在 $[a,b]$ 上连续且严格单调，则区间内有且仅有一个根，即根存在且唯一。工程中通常先通过符号扫描确定有根区间，再结合单调性判断根的唯一性。

工程上常用**逐步搜索法**寻找有根区间：在实轴上取离散点，计算函数值符号，寻找两端异号的区间。

**例 1** 求方程 $f(x) = x^3 - 11.1x^2 + 38.8x - 41.77 = 0$ 的有根区间。

**解** 逐点计算函数符号，结果如表 1。

**表 1 函数符号表**

| $x$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|:---:|---:|---:|---:|---:|---:|---:|---:|
| $f(x)$ 的符号 | − | − | − | + | − | − | + |

可见满足 $f(a)f(b)<0$ 的区间：**[2,3]、[3,4]、[5,6]**，这三个都是有根区间。

### 二分法

> **直观理解：猜数字游戏**
>
> 二分法的思想类似猜数字游戏：给定一个范围，每次取区间中点，判断目标在中点左侧还是右侧，直接舍弃一半区间。二分法利用连续函数介值定理，不断对半压缩有根区间，逼近真实根。

设 $[a,b]$ 为有根区间，满足 $f(a)f(b)<0$。二分法步骤：

1. 取区间中点 $x_0=\frac{a+b}{2}$；
2. 若 $f(x_0)=0$，$x_0$ 即为根；
3. 若 $f(a)f(x_0)<0$，根落在 $[a,x_0]$，令新区间 $[a_1,b_1]=[a,x_0]$；
4. 否则根落在 $[x_0,b]$，令新区间 $[a_1,b_1]=[x_0,b]$。

新的有根区间长度为原来区间的一半。重复该过程，得到区间套：

$$
[a,b]\supset [a_1,b_1]\supset [a_2,b_2]\supset\cdots\supset [a_k,b_k]\supset\cdots
$$

第 $k$ 次二分后的区间长度：

$$
b_k - a_k = \frac{b-a}{2^k}.
$$

当 $k\to\infty$，区间长度趋于 0，区间将收敛到唯一的点 $x^*$，就是方程的根。

取区间中点 $x_k=\frac{a_k+b_k}{2}$ 作为近似根，则误差估计：

$$
|x^* - x_k| \le \frac{b_k - a_k}{2} = \frac{b-a}{2^{k+1}}.
$$

（式 2）

式（2）称为二分法的先验误差界——无需实际执行迭代，即可根据初始区间长度和迭代次数提前估算误差上限，这是二分法最突出的理论特点。

从收敛速度来看，二分法的误差按固定比例 $1/2$ 递减，属于典型的线性收敛。一般地，记第 $k$ 步迭代误差为 $e_k = |x^* - x_k|$，若满足

$$
\lim_{k\to\infty} \frac{|e_{k+1}|}{|e_k|} = C, \quad 0<C<1,
$$

则称该迭代方法为**线性收敛**，常数 $C$ 称为收敛因子。二分法的收敛因子 $C=1/2$，每迭代一步误差减半。

给定精度 $\varepsilon>0$，可以预先估算需要迭代多少次，使得 $|x^*-x_k|<\varepsilon$。

**例 2** 求方程 $f(x)=x^3-x-1=0$ 在 $[1.0,1.5]$ 内实根，要求精确到小数点后第 2 位。

**解** $a=1.0,b=1.5$，$f(a)<0,f(b)>0$，满足有根条件。

由误差估计式（2）：

$$
|x^*-x_k|\le \frac{1.5-1.0}{2^{k+1}}.
$$

要求小数点后 2 位，可取误差限 $\varepsilon=0.005$。解

$$
\frac{0.5}{2^{k+1}}<0.005,
$$

得 $k\ge6$，二分 6 次即可达到精度。

#### 二分法算法步骤

1. 准备：输入区间端点 $a,b$，精度 $\varepsilon$，最大迭代次数；计算 $f(a),f(b)$。若 $f(a)f(b)\ge0$，区间不保证含根，终止。
2. 二分：计算中点 $x=\frac{a+b}{2}$，求 $f(x)$。
3. 判断：
   - 若 $f(x)=0$，$x$ 即为精确根，停止；
   - 若 $f(a)f(x)<0$，令 $b=x$；否则令 $a=x$。
4. 收敛检验：若区间长度 $b-a<\varepsilon$，取中点作为近似根，结束；否则回到步骤 2 继续迭代。

**算法 1 二分法求根算法**

```text
输入：目标函数 f，初始区间端点 a, b，精度容差 ε，最大迭代次数 N_max
输出：方程 f(x)=0 的近似根 x*

function Bisection(f, a, b, ε, N_max)
    if f(a) * f(b) >= 0 then
        报错：区间端点同号，无法保证存在根
        return None
    end if

    for k ← 1 to N_max do
        x ← a + (b - a) / 2        // 稳健中点计算，避免溢出
        f_x ← f(x)

        if (b - a) / 2 < ε or f_x = 0 then
            return x
        end if

        if f(a) * f_x < 0 then
            b ← x
        else
            a ← x
        end if
    end for

    警告：达到最大迭代次数，未收敛
    return (a + b) / 2
end function
```

> **二分法小结与避坑指南**
>
> **优点**：实现简单；仅要求函数连续；**全局收敛**，是稳定可靠的保底算法。
>
> **缺点**：收敛速度慢（线性收敛，每迭代一次误差减半）；当精度要求很高时迭代次数多；仅能求解实根，不能处理复根；只利用了函数值的符号信息，完全未利用函数的导数等更丰富的局部信息，未能进一步加速收敛。
>
> **重要局限**：**不能求解偶数重根**。如 $f(x)=(x-1)^2=0$，根两侧函数值同号，介值定理条件不满足，二分法无法识别。
>
> 工程上二分法常作为预处理：先用二分法锁定根所在小区间，再用牛顿法等快速迭代算法精细求解。

#### 数学小常识：二分法的由来

二分不断缩小区间的朴素思想源远流长。古巴比伦人就曾利用对半分割区间的思路估算平方根；古希腊《几何原本》记载了不断对半分割区间逼近目标量的思想；阿基米德的穷竭法，本质上也是反复二分区间逼近圆周率。

但是二分法严格的理论基础直到 1817 年才由捷克数学家波尔查诺（Bernard Bolzano）建立。他在证明介值定理（零点存在定理）的论文中，系统阐述不断对半缩小区间寻找零点的算法，为二分法建立了严格数学基础。之后柯西在 1821 年的分析讲义中将二分法收录，使其成为标准的数值求根方法。

注意区分：古希腊芝诺提出的“二分悖论”，是哲学层面讨论无穷分割带来的逻辑难题；数值分析中的二分法则主动利用区间二分的极限思想求解近似根，二者名称相近，但研究目的完全不同。

另外注意辨析：数值求根的二分法，不等同于计算机数据结构中的二分查找。二者都是不断缩小搜索范围，但二分法针对连续实数区间，依靠介值定理寻找函数零点；二分查找针对离散有序数组，查找指定元素。

进入计算机时代后，二分法凭借绝对收敛、代码简单的优势，成为数值软件中常用的保底算法。

#### 二分法的失效场景

二分法所有结论依赖两条前提：① $f(x)$ 在闭区间 $[a,b]$ 上连续；② 区间两端函数值异号 $f(a)f(b)<0$。一旦前提不成立，二分法会失效。

1. **偶数重根，函数不变号**  
   取 $f(x)=(x-1)^2=0$，根 $x=1$ 是二重根。任何包含 $x=1$ 的区间，两端函数值均非负，没有变号，二分法完全无法识别。奇重根如 $f(x)=(x-1)^3$，根两侧函数变号，仍然可以使用二分法。

2. **区间内存在间断奇点，不是方程的根**  
   函数 $f(x)=\frac{1}{x}$，取区间 $[-1,1]$，端点满足 $f(-1)=-1,f(1)=1$，端点异号。但区间中点 $x=0$ 是间断点，方程在此区间内无根。二分法会不断逼近间断点，误将奇点判定为根。

3. **单个区间包含多个根**  
   当区间内存在多个根时，二分法只会锁定其中一个根，其余根会丢失。使用二分法前，一般需要预先扫描，将多个根拆分到各自独立的小区间。

4. **无法求解复根**  
   二分法建立在实数区间的介值定理之上，只能搜索实轴上的实根，无法求解复数域内的复根。高次多项式的复根需要使用专门的复域算法（如 Jenkins-Traub 方法）求解。

一句话总结：连续条件下，端点变号是区间存在根的充分条件，但不是必要条件；端点变号不一定代表存在根（间断奇点），区间内有根也不一定端点变号（偶重根）。

#### 拓展：迭代停止条件怎么选？

二分法有两种常用的迭代终止条件，初学者很容易混用，带来数值错误：

1. **区间长度判停（二分法推荐）**：$b-a<\varepsilon$。  
   根据误差估计 $|x^*-x_k|\le \frac{b-a}{2}$，该判据可以给出严格的误差上界，是二分法独有的优势，可靠性高。

2. **函数值判停：$|f(x_k)|<\varepsilon$**  
   谨慎使用！如果根附近函数图像平缓，导数很小，会出现 $f(x_k)$ 已经接近 0，但自变量 $x_k$ 和真实根差距很大的情况，造成“函数很小，根不准”的假象。

工程实践中优先选择区间长度判停，同时设置最大迭代次数，防止死循环。

#### 计算机浮点数实现注意事项

1. 中点计算：简单写法 `mid = (a + b) / 2`，当 $a,b$ 是很大的浮点数时，会出现浮点溢出。更稳健写法：`mid = a + (b - a) / 2`。
2. 机器精度极限：迭代到后期，$a,b$ 在计算机浮点数下无法继续对半分割，区间长度不再缩小，迭代自然终止，无法无限提高精度。

#### 方法导读：二分法和后续迭代算法

二分法最大优势是全局收敛、稳定；代价是收敛速度仅为线性，迭代较慢。

后续章节将学习：

- 试位法（割线法前身）：保留包围根的区间特性，尝试提升收敛速度；
- 牛顿迭代法：利用导数，二次收敛，求解速度快，但无法保证收敛，依赖合适的初始值。

工程常用组合策略：先用二分法锁定根所在小区间，再用牛顿法快速精细求解。

下面给出二分法 Python 代码实现，和上面算法步骤一一对应：

**代码 1 二分法 Python 实现**

```python
def bisection_method(f, a, b, tol=1e-6, max_iter=100):
    """
    使用二分法求解非线性方程 f(x) = 0 的根
    参数:
        f: 目标函数
        a, b: 初始有根区间
        tol: 容差（精度）
        max_iter: 最大迭代次数
    返回:
        近似根
    """
    if f(a) * f(b) >= 0:
        print("错误：区间端点函数值同号，无法保证区间内存在根")
        return None

    for i in range(max_iter):
        mid = a + (b - a) / 2.0
        f_mid = f(mid)

        # 判断是否满足精度要求
        if (b - a) / 2.0 < tol or f_mid == 0:
            return mid

        # 判断根所在的区间
        if f(a) * f_mid < 0:
            b = mid
        else:
            a = mid

    print("警告：达到最大迭代次数，未收敛到指定精度")
    return (a + b) / 2.0


# 示例调用
if __name__ == "__main__":
    def func(x):
        return x**3 - x - 1

    root = bisection_method(func, 1.0, 1.5)
    print(f"方程的根近似为: {root}")
```

二分法的优点是算法简单，且总是收敛的；缺点是收敛速度偏慢，一般不单独用于高精度求解，更多用于定位根的初始区间，为其他迭代方法提供初值。
