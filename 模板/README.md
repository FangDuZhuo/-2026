# 模板命名与使用说明

## 先分清模板、组稿和整合稿

| 文件类型 | 例子 | 谁来编辑 |
| --- | --- | --- |
| 原始模板 | 本章 `模板/模板-A组-正文.md`、`模板/模板-B组-验证报告.md` | 保留原件，供各组复制 |
| 小组成果 | 本章 `工作/A1组-正文.md`、`工作/B2组-验证报告.md` | 对应小组填写自己的副本 |
| 教材整合稿 | 本章 `工作/整合-正文.md`、`工作/整合-实验.ipynb`、`工作/整合-习题.md` | 整合组汇总已确认内容 |

“模板”统一放在文件名最前面，方便识别。A/B/C是本章角色；G编号是固定的实际学生小组。每章同一角色有两组，原分组表从左到右分别叫第1组、第2组。**不能自己挑1或2**，应查[章节分工表](../协作管理/章节分工表.md)。同一A1组称呼在不同章节可能对应不同G组；需要跨章引用时，同时写章号和G编号。

例如G22在第01章叫A2组，在第02章叫B2组，在第03章叫C2组；不是永久叫A2。公开只填组别，不写姓名或GitHub账号。D1—D3、E1—E3沿用原名；第09章的组别待安排。

## 在JupyterLab里复制到工作目录并改名：第一次照着做

每章根目录只保留入口README以及 `模板/`、`工作/` 两个文件夹。`模板/` 保存原件；`工作/` 是本章所有小组写作的位置；`工作/图片/` 放实际使用的图片。本页所在的仓库根目录 `模板/` 是通用备用库，与章内 `模板/` 不同，正式任务优先用本章专用模板。

下面用**第01章G22承担A2组**举例，其他小组先查章节README换成自己的组号：

1. 完成[环境安装](../教程/01-环境安装与运行.md)，按[Git提交教程](../教程/03-GitHub协作与提交.md)创建自己的任务分支，再启动JupyterLab。
2. 在左侧文件列表依次双击 **教材 → 第01章-误差的代价**，先读README里的组名表，再双击 **模板**。
3. 找到 `模板-A组-正文.md`，在**左侧文件名**上右键，选择 **Copy（复制）**。这是复制文件，不是打开后复制文字；不要选Cut（剪切）。
4. 点击左侧列表上方路径中的 **第01章-误差的代价** 返回本章，再双击 **工作**。在文件列表空白处右键，选择 **Paste（粘贴）**。若菜单不显示，可在文件列表内选中文件后按Ctrl+C（Mac为Command+C），进入目标目录后单击列表空白处，再按Ctrl+V（Mac为Command+V）。
5. 此时 `工作/` 出现 `模板-A组-正文.md`。右键这份新副本 → **Rename（重命名）**，改成 `A2组-正文.md`，按Enter。保留 `.md`；Notebook保留 `.ipynb`。不要只改页面里的标题，不要改成 `.md.txt`。回看 `模板/`，原件应仍然存在。
6. 重复第3—5步，复制本角色其余文件。A组6份、B组5份、C组5份，清单见章节README；本次只复制自己的角色。若 `工作/` 已有本组副本，直接继续编辑，不再复制覆盖旧记录。若粘贴时提示同名文件，先取消并核对，不选择覆盖。
7. 在 `工作/` 打开副本填写。Markdown用右键 **Open With → Editor**；Notebook直接双击。把标题和基本信息改为本章组名、实际G编号与任务范围。`工作/` 和 `工作/图片/` 中的 `.gitkeep` 是空目录占位，留着即可，不用打开、填写或运行。
8. **同步副本里的链接。** 例如 `A2组-正文.md` 中 `[实验](模板-A组-实验.ipynb)` 改为 `[实验](A2组-实验.ipynb)`。报告中的AI对话链接也改为本组文件。Notebook里的Markdown单元同样检查。只修改自己的副本，不要全仓库替换。
9. **复制实际用到的模板插图。** 前八章的插图在本章 `模板/图片/A-章节导入.svg`。用同样的Copy/Paste操作，将图复制到本章 `工作/图片/`；保持这个文件名时，副本中的 `图片/A-章节导入.svg` 可直接使用。图已经存在就先核对内容，不重复覆盖。若要自行改图，另存为如 `A2组-章节导入.svg`，再将自己的正文和Notebook图片链接改成 `图片/A2组-章节导入.svg`。第09章的三格分镜写在 `模板/模板-A组-正文.md` 和实验Notebook模板中，按分镜自行绘图，成图放 `工作/图片/`；`模板/图片/README.md` 另有图片存放说明。
10. 自己新增的结果图放在 `工作/图片/`，如 `A2组-误差曲线.png`；在 `工作/A2组-正文.md` 中写 `![误差曲线](图片/A2组-误差曲线.png)`。图片路径从当前文件所在目录出发，不写自己电脑的绝对路径。
11. 引用其他组时写实际目标：B2若复现本章A1和A2，分别写两份实验文件路径和各自完整commit；不要把所有A链接都改成A2。同章成果都在 `工作/`，可直接用文件名链接；引用其他章时要明确章号和目标路径。只审一部分就明确范围。
12. 保存，Notebook按 **Kernel → Restart Kernel and Run All Cells** 运行并核对输出，再保存。按Git教程提交本组 `工作/` 中的副本及必要图片；不要把模板运行后的偶然变化当作本组成果提交。

完成后，例子的源文件是 `教材/第01章-误差的代价/工作/A2组-正文.md`，原件仍是 `教材/第01章-误差的代价/模板/模板-A组-正文.md`。**编辑工作里的副本，保留模板里的原件。**

## 同一章的两组怎样合作

A1、A2先约定小节与实验范围，分别维护自己的文件，保留另一部分为“由另一组负责”；不要求每组重复写完整章。B1/B2、C1/C2分别保留独立证据，报告写清审阅的A/B组与版本。AI对话也分开为 `A1组-AI对话记录.md`、`A2组-AI对话记录.md` 等，不再往一个共享角色报告里追加两组内容。

整合组汇总为一份完整教材，保留来源与组别，不能直接覆盖一组的文件来冒充合并。若其他分支上已有人使用旧的 `A组-正文.md` 等名字，先保留其修改，再协调迁移到正确小组副本；不要以新模板覆盖已有工作。

## 漫画开场与科学性

前八章已有SVG导入图；第09章提供“机器人下山”的三格分镜供绘制。开场按“情境与猜想→定义与条件→推导→实际运行→回答开场问题”展开。示意图标明示意，实测图给出坐标、参数和数据来源；比喻不替代证明。AI生成图记录工具、提示词、日期、人工修改及来源。

通用模板中的 `模板-A组-导入插图.svg` 仅在本目录有效。复制正文/Notebook到章内 `工作/` 时，把图复制到该章 `工作/图片/` 并改成组名，再把副本中的图片路径改为 `图片/实际图片文件名`。不要留下指向模板目录中不存在文件的链接。

## 什么会显示在整本教材里

当前 `教材/_toc.yml` 使用九章 `模板/` 内的文件展示结构。学生组稿创建后不会自动加入网页目录。整合完成后由整合组切换到本章 `工作/整合-*` 三份文件，步骤见[04生成教程](../教程/04-生成与查看教材.md)。报告、AI对话和参考解答继续在仓库中保留，不必全部列进教材目录。
